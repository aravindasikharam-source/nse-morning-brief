NSE Morning Brief

A pre-market pipeline that fetches once, splits the data three ways, and lets three agents reach independent conclusions before anything gets narrowed. Everything deterministic runs in Python; the agents are spent only on judgment.

The 07:00 hour

07:00 fetch.py pulls and screens. No model involved.
07:05 Agents A, B and C run in parallel on separate slices.
07:25 Orchestrator scores confluence and narrows.
07:30 Brief delivered — file, push, archive.
09:00 Optional refresh — actual gap against plan.
09:15 Market opens. You trade.
deterministic — Python, no model judgment — agent reasoning

Pipeline

Agents

Each reads exactly one slice and never re-fetches prices. Numbers come from the file, never from memory or the web — the single exception is Agent A's live lookup, because no macro event calendar exists in the data.

Agent A

Macro

slice_macro_<date>.json
  • Overnight read. US close, Asia, DXY, US 10Y, Brent, USDINR — what moved and why.
  • Transmission. Crude into OMCs and aviation; USDINR into IT and pharma; 10Y into rate-sensitives.
  • VIX regime and what it implies for risk.
  • Event risk — RBI, CPI, Fed speakers, expiry. Sourced live; absent from the file.
Read WebSearch GIFT Nifty
Agent B

Flows & catalysts

slice_flows_<date>.json
  • FII/DII direction, prior session, date stated explicitly.
  • Results today — earnings only, not fund-raising or AGM housekeeping.
  • Verify tags. Confirm or reject each ? match; discard price-list roundups.
  • Block deals — read direction, not size. A crossed block moves no net stock.
  • Theme clusters of three or more real stories.
Read pre-tagged symbols
Agent C

Technical

slice_technical_<date>.json
  • Reject noise. ATR over 6%, RSI over 75, volume ratio under 1.0.
  • Rank by volume confirmation, trend alignment, proximity to the 20-day high.
  • Flag ATR-floor stops — a name with no structural level of its own.
  • Split intraday from swing. Top 10 across both.
Read precomputed levels

Levels are computed in Python, not by the agent. The stop is the nearest structural level below price, floored at 1 ATR — because every pullback candidate sits on its own 20-day average, and "nearest level" produced 0.03% stops that a normal session takes out by accident.

The dividing line

Every design decision in this pipeline comes from one question: does this need judgment, or does it just need doing?

Machine does recall

  • Reads all 209 company names against every headline and never gets bored
  • Drops anything older than 48 hours — a stale feed served April-2024 items alongside live ones
  • Removes cross-posted duplicates, so a count of three stories is three real stories
  • Nets deal legs per symbol, so a matched block cannot read as accumulation
  • Computes every level, floored at 1 ATR

Agent does precision

  • Decides whether a mention is actually an event
  • Resolves or refuses ambiguous tickers rather than guessing
  • Reads transmission — which sector a crude move actually hits
  • Rejects setups that clear the filters but are extended
  • Flags when the data itself would mislead

Group names shared by several listed entities are suppressed before an agent ever sees them: peeling generic words reduced "Bajaj Finance" to "Bajaj", which four listed entities answer to, and it duly tagged the wrong company onto a Bajaj Auto headline. Any alias more than one symbol claims names a family, not a company.

Screener, not a signal service. Position sizing and the decision to trade are yours.
